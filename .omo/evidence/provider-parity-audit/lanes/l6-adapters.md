## Coverage and equal verdicts

These verdicts are deliberately limited to the stated dimensions, not whole-adapter certification.

- **Devin authorization: equal.** O:crates/gateway/src/compat/devin.rs:49-52 and B:internal/runtime/executor/devin_executor.go:100-105 both use literal `Basic <token>-<token>` and Connect protobuf content type, not conventional base64 Basic. Reviewed strict bounded Connect framing and acquire_devin_first_frame first-frame buffering; no additional verified defect asserted for these paths.
- **Kimi model aliases: equal.** O:crates/gateway/src/compat/kimi.rs:28-34 and B:internal/runtime/executor/kimi_executor.go:1347-1354 map coding/highspeed alias families to kimi-for-coding/kimi-for-coding-highspeed. **Kimi Chat temperature: equal.** O:crates/gateway/src/compat/kimi.rs:49-67 versus B:internal/runtime/executor/kimi_executor.go:1509-1514 preserve only 0.6 with thinking disabled or 1.0 otherwise, removing incompatible temperature. Read provider domain/device identity, direct format routing and chat-link normalization; no full refresh/replay certification claimed.
- **xAI OAuth CLI admission header values: equal.** O:crates/providers/src/xai.rs:145-166 versus B:internal/runtime/executor/xai_executor.go:50-62 use xai-grok-cli, grok-shell and authenticate-response. Read transport-specific base selection and reasoning/tool schema normalization; full grok media/websocket, error and retry matrices remain unverified.
- **MiMo bootstrap URL/chat URL/system marker and bounds: equal.** O:crates/providers/src/mimo.rs:10-24 versus A:src/adapters/mimo-free.ts:10-18,27-31: same canonical URLs, exact admission marker, 50-minute fallback, five-minute early refresh, 15-second timeout and 128-KiB bootstrap cap. O additionally permits loopback; canonical-host/loopback restriction is documented at D:docs/reference-parity.md:39. No whole refresh/retry verdict asserted.
- **Cursor framing/request/tool/exec:** reviewed Connect frame envelope and decoder terminal handling, request text mapping, protobuf fields, reply queue, KV and exec dispatch. Concrete failures L6-01..03. Do not call overall parity equal; client-tool surfacing and exec architecture need further comparison before any separate finding.
- **Kiro request/stream:** reviewed translation, image extraction, tool ID normalization, schema sanitization, AWS framing, reasoning/error/terminal branches and reference turn/event mapping. Concrete failures L6-04..06. Native effort, thinking tag injection, stop-reason/truncation and full retry matrix were not exhaustively adjudicated.
- **Zcode:** read plan identity/cache-control/metadata shaping, provider plan constants, model normalization and relay business-error/captcha replay branch. No matching dedicated Zcode adapter was located in the specified A adapter tree or B provider-specific executors. **Not equal-certified**: lack of a matching reference is not evidence of parity or a defect.
- **OpenCode:** read account Bearer/UA header builder and generic relay dispatch. No dedicated OpenCode inference adapter was located in specified reference trees. **Not equal-certified**; no claim of complete path/header/model parity.
- **Command Code:** reviewed reference wrapper/headers/native tool pairing/NDJSON and our credential selection/generic dispatch; L6-07.
- **Interactions:** read eligibility gate and reference Devin Interactions input translation; L6-08. Reference B translator subtree and endpoint OAuth/model test suites were not exhaustively read.
- **AgentRouter:** read A:src/adapters/agentrouter.ts endpoint scoping, originator and language framing. No lane finding asserted because our corresponding host-specific behavior was not traced to sufficient depth.
