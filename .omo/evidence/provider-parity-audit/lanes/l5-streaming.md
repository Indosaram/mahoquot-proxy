## Coverage and equal verdicts

These are narrow behavioral equalities, not assertions that entire files or providers are equivalent.

- **equal - multiline SSE data and optional space:** O `compat/events.rs:207-224` joins data lines with newline and strips at most one leading space; A `src/lib/sse-decoder.ts:25-34`, `:265-276` plus `:161-179` follows the same data-field/payload semantics. O normal parser handles CR, LF, CRLF across chunks (`:155-165`). Anthropic preflight is a separate string scanner and is not covered by this equality (L5-04).
- **equal - complete downstream frame boundaries:** O `compat/render.rs:6-15` writes `data: ...\n\n`; B `internal/runtime/executor/helps/relay_sse_buffer.go:39-57` buffers to blank-line boundaries. Generated ticks are separate renderer output, never inserted into partially forwarded upstream JSON. Raw image and binary bodies use unmodified byte copying (`relay.rs:2628-2628`).
- **equal - translated truncation is not synthetic success:** O `compat/events.rs:103-125` and `compat/render.rs:438-443` emit a terminal failure on missing completion; A `src/server/chat-native-sse.ts:294-305` and B `internal/runtime/executor/claude_executor_stream.go:476-491` flag missing terminal. Equality excludes raw passthrough (L5-01). `[DONE]` is output for chat; it is not accepted as a Responses completed event (`compat/events.rs:229-232`).
- **equal - no failover after returning a streaming response:** O success path returns the counted body (`relay.rs:6380-6401`); errors during body consumption finalize rather than reenter account selection (`:710-721`). B `sdk/api/handlers/claude/code_handlers.go:289-305` preserves committed SSE and sends streaming errors rather than replacing HTTP status/JSON. O transport errors are rendered in the chosen protocol (`compat/mod.rs:686-699`), not appended raw HTTP JSON.
- **equal - cancellation and demand-driven flow:** O `relay.rs:659-666`, `:675-721` drops inner body and finalizes exactly once using `outcome.take()` (`:365-368`). A `src/server/chat-native-sse.ts:319-328` cancels the upstream reader, releases queued buffers, and settles once. O translated pending frames are drained before polling upstream (`compat/mod.rs:645-657`); A queue has explicit 1024-item default and overflow termination (`src/adapters/run-turn-queue.ts:65-70`, `:109-123`). These are different backpressure mechanisms, not proof of identical memory ceilings for every decoder/tool accumulator.
- **equal - usage finalization is single-owner:** O capture is replaced with terminal usage, not summed repeatedly (`compat/mod.rs:733-758`); finalizer takes its outcome once and prefers upstream capture to wire extraction (`relay.rs:365-382`). A Anthropic tap merges latest cumulative usage fields rather than summing snapshots (`src/server/claude-messages.ts:226-230`) and uses settled gating (`:335-346`). No double-counting defect established in these paths.
- **equal - 429 cooldown precedes next-account selection:** O `relay.rs:6480-6494` records cooldown then continues; A `src/oauth/generic-account-failover.ts:205-225` records cooldown then chooses another eligible account. O deliberately distinguishes exhausted quota from shared transient rate limits in failover-budget consumption (`relay.rs:6483-6491`); do not flatten those into one retry class. Date parsing is not equal (L5-05).
- **Status-classification coverage (not an equal verdict):** O `relay.rs:6550-6556` retries 500/502/503/504; classification was inspected alongside 403/408/429 handling (`:32-34`, `:6620-6649`). This audit does not claim all provider-specific status mappings equal across references.
- **equal - WebSocket cancellation can progress under output backpressure:** O `wsrelay.rs:515-565`, `:657-672` uses concurrent directional pumps with bounded writes and drops the losing pump; no unbounded per-connection output queue. O `:594-619` removes terminal turn IDs before recording usage, avoiding duplicate terminal billing. No WS FIX established. Liveness is 300s and frame limit 16 MiB (`:44-46`).
