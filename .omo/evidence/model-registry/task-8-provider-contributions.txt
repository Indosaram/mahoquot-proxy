Task 8: Convert Provider Implementations to Typed Registry Contributions
Location: mahoquot-proxy / mahoquot-providers & mahoquot-registry

1. SUMMARY
----------
Task 8 converts provider implementations in `crates/providers` from declaring
disparate hardcoded model string arrays (`*_MODELS`) as authoritative sources to
declaring and emitting typed registry contributions (`ProviderContribution`) and
querying their supported models and capability profiles directly from catalog/registry
types (`RegistrySnapshot`, `ModelDescriptor`, `ProviderBinding`, `ModelCapability`).

Key Changes:
- `crates/registry/src/lib.rs`:
  - Enhanced `ProviderContribution` to include `policy: Option<ProviderPolicy>`,
    `aliases: Vec<ModelAliasRule>`, and helper methods:
    - `supports_model(&self, model: &str) -> bool`
    - `capability_profile(&self, model: &str) -> Option<BTreeSet<ModelCapability>>`
    - `supported_model_ids(&self) -> Vec<String>`
    - `model_ids(&self) -> Vec<ModelId>`
    - `has_prefix_support(&self) -> bool`
  - Added `RegistrySnapshot::contribution_for_provider(&self, provider_id: &ProviderId) -> ProviderContribution`
  - Added `RegistryBuilder::add_alias_rule(&mut self, rule: ModelAliasRule) -> Result<&mut Self, RegistryError>`
  - Enforced that prefix matching is guarded by `provider_id == ProviderId::vertex()`
    and `has_prefix_support()`.
- `crates/providers/Cargo.toml`:
  - Added `mahoquot-registry.workspace = true`.
- `crates/providers/src/antigravity.rs`:
  - Added `provider_id()`, `contribution(snapshot)`, `default_contribution()`,
    `supported_models(snapshot)`, `is_antigravity_model_in_snapshot(snapshot, model)`,
    and updated `is_antigravity_model(model)`.
  - Deprecated legacy `ANTIGRAVITY_MODELS`.
- `crates/providers/src/claude.rs`:
  - Added `provider_id()`, `contribution(snapshot)`, `default_contribution()`,
    `supported_models(snapshot)`, `is_claude_model_in_snapshot(snapshot, model)`,
    and updated `is_claude_model(model)`.
  - Deprecated legacy `CLAUDE_MODELS`.
- `crates/providers/src/codex.rs` (new module):
  - Created provider adapter for Codex with typed contribution, `default_contribution()`,
    `supported_models()`, `is_codex_model()`, `is_codex_model_in_snapshot()`,
    and re-exports of `account::*`.
- `crates/providers/src/cursor.rs`:
  - Added `provider_id()`, `contribution(snapshot)`, `default_contribution()`,
    `supported_models(snapshot)`, `is_cursor_model_in_snapshot(snapshot, model)`,
    and updated `is_cursor_model(model)`.
  - Deprecated legacy `CURSOR_MODELS`.
- `crates/providers/src/kiro.rs`:
  - Added `provider_id()`, `contribution(snapshot)`, `default_contribution()`,
    `supported_models(snapshot)`, `is_kiro_model_in_snapshot(snapshot, model)`,
    and updated `is_kiro_model(model)`.
  - Preserves `kiro/` virtual prefix and unprefixed upstream IDs.
  - Deprecated legacy `KIRO_MODELS`.
- `crates/providers/src/vertex.rs`:
  - Added `provider_id()`, `contribution(snapshot)`, `default_contribution()`,
    `supported_models(snapshot)`, `is_vertex_model_in_snapshot(snapshot, model)`,
    and updated `is_vertex_model(model)`.
  - Preserves prefix matching rules for `gemini-*` and `google/*`.
  - Deprecated legacy `VERTEX_MODELS`.
- `crates/providers/src/zcode.rs`:
  - Added `provider_id()`, `contribution(snapshot)`, `default_contribution()`,
    `supported_models(snapshot)`, `is_zcode_model_in_snapshot(snapshot, model)`,
    and updated `is_zcode_model(model)`.
  - Deprecated legacy `ZCODE_MODELS`.
- `crates/providers/src/lib.rs`:
  - Registered and exported `codex` module; re-exported `is_codex_model`,
    `is_codex_model_in_snapshot`.
- `crates/gateway/src/management/oauth.rs`:
  - Updated device OAuth session creation to read default models from the catalog/registry
    at creation time (`embedded_snapshot().contribution_for_provider(&pid)`).
- `crates/providers/tests/provider_contributions_tests.rs`:
  - TDD integration suite asserting all 7 providers emit expected contributions,
    100% parity with legacy lists, accurate capability profiles, and dynamic catalog support.
