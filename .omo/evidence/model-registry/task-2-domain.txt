## 1. Executive Summary
Task 2 delivers the pure domain crate `mahoquot-registry` defining all core domain types, provider admission policies, source authority masks, capabilities, provider bindings, alias/exclusion rules, immutable snapshots, and builder validation.

Key invariants:
- Pure domain crate: Zero I/O, no tokio, no reqwest, no axum, no arc-swap, no account secrets, and no gateway dependencies.
- Deterministic data structures: All collections use `BTreeMap` and `BTreeSet`, guaranteeing byte-stable serialization and predictable iteration order.
- TDD RED -> GREEN cycle: 8 comprehensive unit/contract tests written first (7 failing on unimplemented stub, 1 passing), then implemented and verified completely green.
- Verified policy semantics:
  1. Closed binding wins when resolving a model with explicit closed provider bindings.
  2. Open Codex cannot steal models claimed by closed or discovered bindings.
  3. Discovered fallback is bounded: discovered providers cannot serve arbitrary unclaimed models.

## 3. Strongly Typed Domain Inventory

| Type | Kind | Role & Invariants |
| --- | --- | --- |
| `ProviderId` | Newtype (`String`) | Rejects empty strings, whitespace, and control characters. Predefined helpers: `codex()`, `antigravity()`, `claude()`, `cursor()`, `kiro()`, `vertex()`, `zcode()`. |
| `ModelId` | Newtype (`String`) | Rejects empty strings, whitespace, and control characters. |
| `CatalogVersion` | Newtype (`u64`) | Monotonic catalog schema version. |
| `CatalogSource` | Enum | `LocalOverride` (precedence 5) > `Discovered` (4) > `RemoteSigned` (3) > `LkgCache` (2) > `EmbeddedFallback` (1). |
| `ProviderPolicy` | Enum | `Closed` (Antigravity/Claude/Cursor/Kiro/Vertex/Zcode), `Discovered` (explicit adapter accounts), `Open` (Codex only fallback). |
| `AuthorityMask` | Struct | Fine-grained boolean flags: `models`, `capabilities`, `aliases`, `prefixes`, `upstream_id`. Preserves existing fields when merging lower-authority sources. |
| `ModelCapability` | Enum | `Chat`, `Image`, `Video`, `Realtime`, `CountTokens`, `Embedding`, `Audio`, `Tools`. Supports case-insensitive/kebab-case parsing via `from_str_loose`. |
| `ProviderBinding` | Struct | Binds `(ModelId, ProviderId)` with upstream ID, capabilities set, authority mask, priority, and deterministic `merge_with` logic. |
| `ModelDescriptor` | Struct | Canonical model descriptor: `id`, `owned_by`, `display_name`, `capabilities`, `bindings: BTreeMap<ProviderId, ProviderBinding>`, `aliases`, `metadata`. |
| `ModelAliasRule` | Struct | Alias to canonical target with optional provider scoping. |
| `ModelExclusionRule` | Struct | Global or per-provider exclusion. |
| `RegistryError` | Enum | Typed error variants: `EmptyProviderId`, `InvalidProviderId`, `EmptyModelId`, `InvalidModelId`, `UnknownModel`, `UnknownProvider`, `AliasCycle`, `AliasDepthExceeded`, `UnknownAliasTarget`, `DuplicateBinding`, `ModelExcluded`, `NoRoutableModels`, `SerializationError`, `DeserializationError`. |
| `RegistrySnapshot` | Struct | Immutable snapshot holding `BTreeMap<ModelId, ModelDescriptor>`, `BTreeMap<ProviderId, ProviderPolicy>`, `BTreeMap<ModelId, ModelAliasRule>`, `BTreeSet<ModelExclusionRule>`. Supports `resolve`, `capabilities_for`, `to_json_canonical`, `from_json`. |
| `RegistryBuilder` | Struct | Fluent builder with validation of alias cycles, chain depth (max 10), unknown targets, and routability. |

Evaluation:
1. Closed binding wins: Model with Closed provider binding `claude` resolves to `ProviderId(claude)` as first/only eligible binding.
2. Open Codex cannot steal claimed ID: Despite Codex (Open) being registered in snapshot, it does not appear in bindings for either `claude-sonnet-4-6` or `deepseek-chat`.
3. Discovered fallback bounded: Discovered provider `custom-gateway` cannot serve `custom-unclaimed-model`; it falls through to Open Codex.
4. Without Open provider: Unclaimed model fails cleanly with `RegistryError::UnknownModel`.
PASS criterion fully satisfied.
