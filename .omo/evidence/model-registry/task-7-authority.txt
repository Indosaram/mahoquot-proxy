1. SUMMARY
----------
Task 7 implements explicit provider discovery policies and typed contributions
in `mahoquot-registry`:
- Provider Policies:
  - `Closed`: Dedicated providers (Claude, Antigravity, Kiro, Cursor, Vertex, Zcode)
    only expose catalog-declared models. Dynamic discovery cannot add models here.
    Unauthorized discovery contributions are rejected with typed
    `RegistryError::UnauthorizedContribution`.
  - `Discovered`: Providers (e.g. local accounts / adapters / custom device auth)
    discover models dynamically with explicit authority masks (chat/tools/image etc.)
    and cannot overwrite catalog capabilities or alias targets.
  - `Open`: Provider (Codex) accepts arbitrary model identifiers dynamically,
    with optional negative-space exclusions.
- Typed Contributions:
  - `DiscoveredModel { id, capabilities, context_limit, authority }`
  - `ContributionItem::Descriptor(ModelDescriptor)` / `ContributionItem::Discovered(DiscoveredModel)`
  - `ProviderContribution { provider_id, models: Vec<ContributionItem> }`
- RegistryBuilder Invariant:
  - Rejects dynamic discovery for Closed providers via `apply_contribution`.
  - Merges discovered models for Discovered/Open providers without overwriting
    higher-precedence catalog capabilities.
  - Rejects unknown providers with `RegistryError::UnknownProvider`.
