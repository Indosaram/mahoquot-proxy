## 1. Executive Summary
Task 3 consolidates every hardcoded model list and seed source previously scattered across:
- `crates/providers/src/antigravity.rs` (14 ANTIGRAVITY_MODELS)
- `crates/providers/src/claude.rs` (12 CLAUDE_MODELS)
- `crates/providers/src/zcode.rs` (5 ZCODE_MODELS)
- `crates/providers/src/kiro.rs` (8 KIRO_MODELS, exposed as kiro/{model}, auto-kiro alias)
- `crates/providers/src/cursor.rs` (4 CURSOR_MODELS in /v1/models + 2 cursor-* models)
- `crates/providers/src/vertex.rs` (21 VERTEX_MODELS)
- `crates/gateway/src/models_route.rs` (7 Codex DEFAULT_MODELS)
- `crates/gateway/src/capability.rs` (2 IMAGE_MODELS, 0 VIDEO_MODELS)
- `crates/gateway/src/management/oauth.rs` (Device OAuth default models: Kimi 5, Qwen 4, Nous 4, GitHub Copilot 5)
- OpenCode presets (Opencode-Go, Opencode-Free, Opencode-Zen)

All models are centralized into a single canonical source-of-truth JSON artifact:
`crates/registry/catalog/models-v1.json`

The artifact is statically embedded in `mahoquot-registry` via `include_str!` and exposed via:
- `pub fn embedded_catalog() -> &'static str`
- `pub fn embedded_catalog_bytes() -> &'static [u8]`
- `pub fn embedded_registry_snapshot() -> Result<RegistrySnapshot, RegistryError>`
- `pub fn embedded_snapshot() -> &'static RegistrySnapshot`
